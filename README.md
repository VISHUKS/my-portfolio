# Pankaj Kumar Singh — AI Motion Graphics Designer & Creative Video Editor

An immersive, cinematic portfolio showcasing the intersection of **Artificial Intelligence, Motion Graphics, Visual Storytelling, and Video Editing**.

Created for **Pankaj Kumar Singh**, an AI Motion Graphics Designer and Video Editor passionate about transforming creative ideas into visually engaging digital experiences.

---

## Creative Direction & Visual Experience

- **AI-Powered Visual Storytelling:** Showcases creative video projects combining AI-generated visuals, motion design, cinematic editing, and digital creativity.
- **Cinematic Dark Aesthetic:** Deep obsidian background (`#06070a`), subtle film grain, high-contrast typography, and electric lime accents (`#ccff00`).
- **Interactive Ambient Spotlight:** Cursor-following radial lighting creates an immersive visual experience with glowing portfolio card borders.
- **Creative Editor HUD:** Animated timecode, REC indicator, audio equalizer visualizer, and cinematic timeline playhead.
- **Infinite Motion Marquee:** Continuous animated ticker highlighting AI creativity, motion graphics, video editing, and visual storytelling.
- **Dynamic Video Showcase:** Interactive video gallery featuring long-form cinematic edits and short-form social media content.
- **Accessible Video Modal:** Videos load dynamically on interaction using YouTube's privacy-enhanced embed player, with keyboard accessibility and automatic playback cleanup.
- **Smart Thumbnail Fallbacks:** Supports high-resolution and standard YouTube thumbnails with graceful visual fallbacks.
- **Interactive Project Filtering:** Browse projects through dedicated categories:
  - All Projects (14)
  - Long-Form Videos (16:9) (6)
  - Short-Form Reels (9:16) (8)
- **Animated Collaboration Section:** Rotating neon border beam creates a distinctive closing call-to-action.

## Run Locally

Open `index.html` directly in any modern browser.

Alternatively, run a local server:

```powershell
cd "d:\Pankaj_Portfolio"
python -m http.server 3000
```

Open:

`http://localhost:3000`

## Deployment

This portfolio can be hosted for free using **GitHub Pages**.

1. Push the project to a public GitHub repository.
2. Open Repository Settings.
3. Navigate to Pages.
4. Select Deploy from a branch.
5. Choose `main` and `/ (root)`.
6. Save and wait for deployment.
